# 書き順ガイドデータ

`strokes.json` のガイド線とチェックポイントは、[AnimCJK](https://github.com/parsimonhi/animCJK) の日本語かなSVGに含まれるメディアン線を、練習画面の `0 0 200 200` 座標へ変換したものです。

対象ファイルは、Unicodeコードポイントで次の5つです。

- `12354.svg`（あ）
- `12356.svg`（い）
- `12358.svg`（う）
- `12360.svg`（え）
- `12362.svg`（お）
