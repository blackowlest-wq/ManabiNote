# 動物ラスター画像アトラス設計

## 1. 目的

幼児向けひらがな問題で使用する動物イラストを、既存の簡易SVGから、添付された猫のイラストを参考にした高品質なラスター画像へ置き換える。まず動物分類だけを対象とし、他の食べ物・もの・自然の画像は変更しない。

既存画像を比較・復元できるよう、現在の `animals-01.svg` は上書きしない。新しい画像は別ファイルとして追加し、問題表示が新画像を参照する場合も旧画像を残す。

## 2. 決定事項

### 2.1 画像の作成単位

動物26種類を1回の画像生成でまとめて作らず、1種類ずつ生成する。各画像を確認し、動物の種類・表情・全身の収まり・タッチが不十分なものだけ個別に再生成する。

生成時は添付画像をスタイル参考として使用する。共通条件は次のとおりとする。

- かわいらしい幼児向けイラスト
- 丸みのある形、太めの濃色アウトライン、淡い色合い
- 正面または少し斜め向きの全身
- 1匹だけを中央に配置し、十分な余白を確保
- 文字、ロゴ、透かし、不要な小物を含めない
- 26種類で背景・余白・画面内の大きさを揃える

### 2.2 アトラス形式

個別生成した画像を、最終的に1枚のWebPラスター画像へ合成する。6列×5行の固定グリッドを使い、26種類を収める。予備4マスは空けておき、将来の追加や差し替えに利用できる。

- 出力ファイル: `public/images/kana-to-picture/atlases/animals-01-v2.webp`
- 推奨キャンバス: 1,920×1,600px
- 1マス: 320×320px
- 出力ファイルサイズ: 25MB未満。目標は25MBより十分小さい容量
- 生成元の個別画像は一時作業用とし、アプリのPWAキャッシュ対象には含めない

WebPで容量が大きくなった場合は、品質を下げるかキャンバスを縮小して再出力する。PNGは透過が必要な場合の代替とするが、今回のカード表示では背景を統一したWebPを第一候補とする。

### 2.3 アプリでの切り出し

現在のSVG `<symbol>` 参照を、ラスターアトラスのグリッド切り出しに対応させる。マニフェストの動物アトラスに、画像形式、列数、行数、セルサイズを追加する。シンボルの並び順は既存の26種類を維持し、行優先でセル位置を決める。

表示コンポーネントは、動物アトラスの場合だけ画像を背景画像として設定し、対象セルの位置を `background-position` で表示する。他の3分類は当面これまでのSVGシンボル表示を維持する。代替テキストと `aria-label` は現行どおり問題データのラベルから提供する。

### 2.4 問題データとの関係

動物アトラスの26シンボルをすべて問題の選択肢から参照できるようにする。未使用の `いるか`、`ぞう`、`かえる` は4択目として組み込む。問題形式は4択へ拡張し、正解1つと誤答3つを持つ。

説明句は単純な呼び名へ統一する。少なくとも次を置き換える。

- `ねこのこ` → `ねこ`
- `こいぬ` → `いぬ`
- `せのたかいきりん` → `きりん`
- `わらうぱんだ` → `ぱんだ`
- 画像と呼び名が一致しない `むし` → `あり`

一般に一語として覚える `おにぎり`、`さくらんぼ`、`あいすくりーむ`、`しろくま` などは維持する。

## 3. データフロー

```text
添付画像をスタイル参考にする
  → 動物を個別生成
  → 個別画像を確認・必要なものだけ再生成
  → 320pxセルへ正規化
  → animals-01-v2.webpへ合成
  → マニフェストでセル配置を解決
  → SpriteImageが該当セルを表示
```

旧 `animals-01.svg` はこの流れから削除せず、比較用・復元用に残す。

## 4. エラー処理

- マニフェストの形式、列数、行数、セルサイズが不正なら既存の問題データエラーとして扱う。
- シンボル数がグリッドのセル数を超える場合は読み込みを拒否する。
- 画像ファイルが存在しない場合は、既存の安全な読み込みエラーへつなげる。
- 画像生成や再生成の途中で品質基準を満たさない場合は、その画像を採用せず、対象動物だけを再生成する。
- 旧SVGは新画像の検証が終わるまで変更・削除しない。

## 5. テストと受け入れ条件

- 旧 `animals-01.svg` が変更されていない。
- 新しいアトラスが存在し、ファイルサイズが25MB未満である。
- 新しいアトラスの26セルがマニフェストの26シンボルと対応する。
- 動物アトラスの画像参照が正しいセルを表示する。
- 既存のSVGアトラス3種類の表示が壊れない。
- 全問題が4択で、正解1つ・誤答3つになっている。
- 誤答が問題のひらがなと同じ語頭にならない。
- 動物26種類が問題選択肢から少なくとも1回参照される。
- `npm run typecheck`、`npm run test`、`npm run build`、`npm run test:pwa` が成功する。
