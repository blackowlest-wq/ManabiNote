# ひらがな選択肢イラスト設計

## 目的

幼児向けひらがな学習アプリの選択肢画像として、「ねこ」「ねこのこ」「めろん」を、文字が読めなくても絵だけで判別できる軽量なSVGとして追加する。

## 共通仕様

- 各イラストは単一ファイルのself-contained SVGとする。
- `viewBox="0 0 256 256"` を使用し、`width` と `height` は指定しない。
- 背景は透明とする。
- 外部画像、base64、JavaScript、不要なmetadata・defs・commentsは使用しない。
- 色数は3〜6色程度に抑える。
- フラットデザイン、太く丸い輪郭、グラデーション・ぼかし・複雑な影なしとする。
- 対象物を中央に大きく置き、上下左右に約10〜15%の余白を残す。
- 小サイズ表示で潰れる細部、文字、ラベルは入れない。

## イラスト構成

### neko.svg

成猫を1匹、全身が見える状態で中央に配置する。三角耳、顔の目鼻、ひげ、長いしっぽを描き、猫らしさを明確にする。丸みのある体形とやさしい表情で幼児向けにする。

### nekonoko.svg

親猫と子猫を並べて配置する。子猫は親猫より明確に小さく、丸い顔・大きな目・短い体形で幼い印象を出す。親猫は単なる成猫画像の再利用にせず、子猫との大きさの対比がひと目で分かる構図にする。

### meron.svg

メロンの実を中央に大きく配置する。楕円形の実に太い網目模様を入れ、上部に茎と葉を添える。単なる丸い果物に見えないよう、メロン特有の網目と外形を優先する。

## 配置

ファイルは既存の画像配置に合わせ、`public/images/kana-to-picture/neko.svg`、`nekonoko.svg`、`meron.svg` とする。

## 検証

SVGのXML構造、viewBox、禁止属性・要素の有無、透明背景、ファイル名と配置を確認する。小サイズ表示を想定し、輪郭・対象物の識別に必要な要素が十分な太さで残っていることを確認する。
