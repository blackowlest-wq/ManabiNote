# アトラス紐づけ確認ページ 設計

## 目的

人が画像と問題中の呼び名の紐づけを確認できるよう、動物・食べ物・もの・自然の4分類を一覧表示する独立ページを追加する。学習画面の動作やレイアウトは変更しない。

## 採用方針

確認ページは `public/kana-to-picture-atlas-review.html` とし、ローカル開発サーバーで `/kana-to-picture-atlas-review.html` を開いて利用する。画像は公開済みのWebPアトラスからCSSの背景位置で各セルを切り出す。

候補として、React画面に確認ルートを追加する方法、個別PNGを公開フォルダーへ複製する方法もあるが、前者は学習画面に不要な責務を増やし、後者は画像を二重に配布する。生成スクリプト付きの独立HTMLなら、既存アトラスを再利用し、問題データから表示名を再生成できる。

## 表示内容

- 4分類を見出し付きで表示する。
- 各カードに画像、アトラス内の行・列、`symbolId` を表示する。
- 問題データ中の各画像に紐づく正式な「ラベル / 読み」を1つ表示する。同じ画像に複数の呼び名があれば生成時にエラーとして扱う。
- アトラスのシンボル順と同じ左上から右方向、次の行の順で並べる。
- モバイル幅でもカードが折り返し、画像と文字が読めるようにする。

## 生成と検証

`scripts/generate-atlas-review.py` がマニフェストと問題JSONを読み、表示用データを埋め込んだHTMLを生成する。生成時に、全マニフェストシンボルが問題データに登場すること、各画像に正式名称が1つだけあること、名前が空でないこと、各アトラスがラスタグリッドであることを検証する。

`scripts/test_atlas_review.py` は生成済みHTMLの分類数、全107カード、全シンボルID、複数表記の保持、4つのWebP参照を確認する。

## 制約

- 新しい依存関係は追加しない。
- 既存の学習画面・問題データ・アトラス画像は確認ページのために変更しない。
- 確認ページは生成物なので、マニフェストまたは問題データを変更した場合は生成スクリプトを再実行する。
