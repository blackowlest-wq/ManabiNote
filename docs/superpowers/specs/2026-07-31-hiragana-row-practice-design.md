# ManabiNote 基本ひらがな行別書き順練習 設計仕様

## 1. 目的

基本ひらがな46文字の書き順練習を追加する。ただし、子供が一度に46文字を練習する負荷を避けるため、あ行・か行などの行単位で練習対象を選び、1回のセッションを短く保つ。

## 2. 対象範囲

### 含める

- 基本ひらがな46文字
- あ行、か行、さ行、た行、な行、は行、ま行、や行、ら行、わ行、んの行グループ
- 行を選んで練習を開始する画面
- 選択した行の文字を固定順で1文字ずつ練習する
- 既存の薄いSVGガイド、なぞり判定、失敗後の色付きヒントを再利用する
- 行の文字数に応じた進捗表示と結果表示

### 含めない

- 濁音、半濁音、拗音、外来音
- 行をまたいだランダム出題
- 自動難易度調整、復習問題の自動混在
- サーバー保存やログイン

## 3. 子供向けの学習体験

ホームから「書き順れんしゅう」を選ぶと、練習する行を選ぶ画面を表示する。初期選択はあ行とし、行ボタンは縦方向に並べて、1回に選ぶ対象を明確にする。

選択後は、その行の文字だけを順番に練習する。通常の行は5文字、や行は3文字、わ行は2文字、んは1文字なので、1セッションの最大文字数は5文字となる。行を終えると結果画面を表示し、選択した行をもう一度練習できる。

## 4. データとアーキテクチャ

- `StrokeRowId` と行定義を `kana-to-stroke` のモデルに追加する
- `strokes.json` は基本46文字を保持し、バリデーターは固定順の46文字を検証する
- 行別の問題取得関数が、行定義の順序に従って問題を返す
- AnimCJKの `svgsJaKana/<Unicode>.svg` に含まれる中央値線を、既存の `guidePath` と `checkpoints` に変換する生成スクリプトを追加する
- `PracticeSession` は選択した `rowId` と、その行の問題だけを保持する
- `StrokePracticeProvider.startPractice(rowId)` が行別セッションを開始する
- 既存の `StrokeCanvas` と判定処理は、入力された問題データをそのまま利用する

## 5. 画面遷移

    ホーム
      └─ 書き順れんしゅう
           └─ 行を選ぶ
                └─ 選択した行を練習
                     └─ 行の結果

セッションがない状態で `/stroke-order` にアクセスした場合も、エラーではなく行選択画面を表示する。

## 6. エラー処理

- 46文字のデータが不足・重複・順序不正の場合は、既存と同じ問題データエラーとして練習を開始しない
- 存在しない行IDを指定した場合は、練習を開始せずエラー状態を表示する
- 行の問題が空の場合は、行選択画面から開始できないようにする
- 既存のなぞり判定エラーとモバイル操作抑止には影響させない

## 7. テスト方針

- モデル: 46文字の固定順、行定義、行別抽出、行別セッション作成を検証する
- データ: 46文字すべてに1画以上のガイドと2点以上のcheckpointがあることを検証する
- 画面: 行選択、選択行の開始、行の文字数に応じた進捗、結果画面の行名と再練習を検証する
- 既存のなぞり、クイズ、履歴、PWAテストを維持する
- `npm test`、`npm run typecheck`、`npm run build`、`npm run test:pwa` を完了時に実行する

## 8. 完了条件

- 基本46文字が行単位で選択できる
- 1回のセッションが最大5文字で完了する
- 各行の文字を正しい順番で練習できる
- 既存の失敗後ヒント、成功色、モバイル操作が維持される
- 行別結果と再練習が機能する
- 静的ビルドとPWAテストが成功する
