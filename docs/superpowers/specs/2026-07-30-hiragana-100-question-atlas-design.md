# ひらがな100問・複数画像アトラス設計

## 1. 目的

幼児向けのひらがな学習問題を現在の5問から約100問へ増やす。問題形式は現在の「ひらがな1文字を見て、対応する絵を3択から選ぶ」を維持し、1回の学習セッションでは引き続き5問を出題する。

問題データと画像を問題形式フォルダ内で管理し、画像が増えてもUIコードと混ざらない構成にする。Cloudflare Pagesの無料枠で運用しやすいよう、複数のSVG画像アトラスへ分割し、各アトラス内の絵をSVGシンボルとして参照する。

## 2. 前提と範囲

- フロントエンドはReact + TypeScript + Viteのまま変更しない。
- 問題データはJSONのまま保持する。
- 1セッションは5問、セッション内の問題重複なしを維持する。
- 正解語は44個の語頭ひらがな（「ん」「を」を除く）を対象とする。
- 44音それぞれ最低2問、追加12問を一般的な音へ配分し、合計100問とする。
- 正解語のreadingは100問で重複させない。
- 各問題は選択肢を3個持ち、正解以外のreadingが問題のひらがなで始まらないことを正規表現で検証する。
- 「ん」「を」は語頭の絵を自然に作りにくいため、現在の問題形式では対象外とし、将来別形式または別の出題ルールで扱える余地を残す。
- 外部画像、外部API、外部フォントは使用しない。
- 履歴削除は現在のアプリが管理する履歴キーだけを削除し、他のlocalStorageデータには影響させない。

Cloudflare Pages Freeの制限は1サイト20,000ファイル、1ファイル25MiBである。100問の画像を複数アトラスへまとめることで、ファイル数とキャッシュ対象をさらに抑える。

## 3. 問題データ設計

### 3.1 問題JSON

既存の `src/features/question-types/kana-to-picture/data/questions.json` を100件へ拡張する。既存の問題形式識別子、問題ID、表示ひらがな、問題reading、3選択肢、正解選択肢ID、任意の音声項目を維持する。

選択肢の画像参照はファイルパスの直接指定から、アトラス参照へ変更する。

```json
{
  "id": "hiragana-a-01",
  "type": "kana-to-picture",
  "kana": "あ",
  "reading": "あり",
  "choices": [
    {
      "id": "ant",
      "label": "あり",
      "reading": "あり",
      "image": { "atlasId": "animals-01", "symbolId": "ant" }
    }
  ],
  "correctChoiceId": "ant",
  "audioSrc": null
}
```

`label`は画面表示とアクセシビリティ用、`reading`は語頭判定用として分離する。漢字表示を将来追加しても、判定に使うreadingは変更しない。

### 3.2 問題数と語彙

100問は次の配分で作る。

- 44音 × 2問 = 88問
- 「あ」「い」「う」「お」「か」「き」「こ」「さ」「た」「な」「は」「ま」に各1問追加 = 12問
- 合計100問

語彙は幼児が認識しやすい動物、食べ物、乗り物、身の回りの物、自然を優先する。読みが長すぎる語、抽象語、同音異義語は避ける。外来語を使う場合は、幼児向けに一般的なひらがな読みで表せるものに限定する。

## 4. 複数画像アトラス設計

### 4.1 ファイル構成

```text
src/features/question-types/kana-to-picture/
├─ data/
│  ├─ image-atlas-manifest.json
│  └─ questions.json
├─ components/
│  ├─ KanaQuestion.tsx
│  ├─ PictureChoice.tsx
│  └─ SpriteImage.tsx
└─ model/
   ├─ imageAtlas.ts
   ├─ types.ts
   ├─ validator.ts
   └─ loader.ts

public/images/kana-to-picture/atlases/
├─ animals-01.svg
├─ food-01.svg
├─ objects-01.svg
└─ nature-01.svg
```

アトラスは分類ごとに複数ファイルへ分割する。初回は4ファイル程度に分け、1ファイルへ絵を詰め込みすぎない。将来追加する場合は、アトラスSVGとマニフェストのエントリを追加するだけで既存コンポーネントは変更しない。

### 4.2 マニフェスト

`image-atlas-manifest.json` は次の形にする。

```json
{
  "atlases": [
    {
      "id": "animals-01",
      "src": "/images/kana-to-picture/atlases/animals-01.svg",
      "symbols": ["ant", "dog"]
    }
  ]
}
```

マニフェストはloaderで一度検証する。アトラスIDの重複、空のパス、空のシンボルID、同一シンボルIDの重複を拒否する。問題JSONの画像参照は、マニフェストに存在するアトラスとシンボルだけを受け付ける。

### 4.3 表示

`SpriteImage`を問題形式フォルダ内に作り、次の責務だけを持たせる。

- アトラス参照をマニフェストから解決する。
- `<svg role="img"><use href="<atlas src>#<symbolId>" /></svg>`を描画する。
- `aria-label`を受け取り、絵の代替名を提供する。
- 参照不備時は問題データを表示せず、既存の安全な読み込みエラーへつなげる。

`PictureChoice`は画像ファイルのパスを解釈せず、`SpriteImage`へ画像参照とラベルを渡す。これにより、将来アトラスが増えても選択肢UIは変更しない。

## 5. 問題データ検証

既存の正規表現による語頭検証を拡張する。

- `reading`が`kana`で始まることを、kanaをエスケープした正規表現`^<kana>`で確認する。
- 正解選択肢のreadingと問題readingが一致することを確認する。
- 正解以外の2選択肢が`^<kana>`に一致しないことを確認する。
- 問題ID、選択肢ID、正解語reading、画像参照の重複と欠落を確認する。
- 100問未満の場合はloaderで開始を拒否する。
- アトラス参照が壊れている場合は、問題データエラーとして扱う。

## 6. 履歴クリア

履歴画面に履歴が1件以上ある場合だけ「履歴をすべて削除」ボタンを表示する。押下時は確認ダイアログを表示し、次の2操作を提供する。

- 「キャンセル」: ダイアログを閉じ、履歴を変更しない。
- 「削除する」: `manabinote.history.v1`だけを`removeItem`し、画面を空状態へ更新する。

Storage操作は`clearHistory(storage)`として履歴ストレージモジュールに閉じ込める。削除に失敗した場合は履歴を画面から消さず、`role="alert"`でエラーを表示する。テスト用ストレージに別キーを置き、履歴削除で別データが残ることを確認する。

## 7. PWAとCloudflare Pages

- Workboxのprecache対象に複数アトラスのSVGを含める。
- PWAテストでマニフェストに列挙された全アトラスのパスがService Workerへ含まれることを確認する。
- 生成ファイル、Service Worker、問題JSON、アトラスがproduction buildに含まれることを確認する。
- オフライン時も、初回オンラインアクセス後に100問とアトラスを利用できる状態を維持する。

## 8. テスト方針

- 型チェックで全ての画像参照型を検査する。
- マニフェストの正常系、重複、未知アトラス、未知シンボルをvalidatorテストで検査する。
- loaderテストで100問、44音、各3選択肢、正解語の重複なしを検査する。
- `SpriteImage`テストでアトラスURLとシンボルフラグメントを検査する。
- QuizPageテストの合計問題数を5問のまま維持し、問題プールが100問でもセッションが成立することを検査する。
- HistoryPageテストで、空状態、キャンセル、確認削除、削除後の空状態を検査する。
- historyStorageテストで`clearHistory`が履歴キーだけを削除することを検査する。
- `npm run test:coverage`のStatements、Branches、Functions、Linesを80%以上にする。
- `npm run build`と`npm run test:pwa`を実行する。

## 9. 受け入れ条件

- 100問のJSONが読み込める。
- 100問の正解readingに重複がない。
- 44音それぞれ2問以上ある。
- 全問題が3択で、誤答の語頭が問題文字と一致しない。
- 画像アトラスが4ファイル以上に分かれていても、JSON参照だけで表示できる。
- PWAオフラインキャッシュに全アトラスが含まれる。
- 履歴を確認操作付きで全件削除でき、他のlocalStorageキーを壊さない。
- 既存の5問セッション、正誤表示、履歴保存、スマホ表示が壊れない。
- カバレッジ各指標が80%以上である。
