# かなと絵問題の命名・選択肢ルール

## 目的

画像と読みの対応を幼児にも判断しやすく保ち、正解位置や選択肢の特徴から答えを推測できない問題バンクを維持する。問題データを変更するときは、この資料のルールと確認ページを基準にする。

## 1. 画像と名前の対応

- `(atlasId, symbolId)` の1画像には、正式な呼び名を1つだけ紐づける。別の言葉を同じ絵の別名として登録しない。
- `label` と `reading` は同じ正式名称を基本とする。漢字などの表示上の差が必要な場合も、読みの意味が同じであることを確認する。
- 名前は、幼児が一般に一語として覚える単純な呼び名を優先する。広すぎる言葉、説明文、場面説明は避ける。
- 同じ読みを別の画像へ付けることも原則避ける。利用者が明示的に指定した例外（現在の「たこ」など）は、同じ問題内に同時に出さない。
- 画像は名前の対象が一つに絞られ、他の候補と見た目が重ならないことを人が確認する。
- 非動物の画像には、目・口・顔・表情・擬人化表現を付けない。

## 2. 1問の選択肢

- 1問は4択で、正解1つ・不正解3つにする。
- 正解の読みは表示かなで始める。不正解は表示かなで始めない。
- 正解と不正解の読みの1文字目を重複させない。
- 同じ問題内で、画像参照・読み・1文字目を重複させない。
- 選択肢IDと問題IDは重複させない。正解IDは4択のいずれか1つを指す。

## 3. 問題バンク全体

- 正解の読みは100問で重複させない。
- 正解位置は1〜4番へ分散し、同じ位置が全体の40%を超えないようにする。現在の100問では各位置25問とする。
- 正解位置の割り当ては再生成しても再現できる方式にし、単純な「1, 2, 3, 4」の繰り返しにはしない。
- 各アトラスの全シンボルを、少なくとも1回は選択肢として使用する。
- 不正解の出現数が一部の画像へ偏りすぎないよう、現在の100問では画像ごとの不正解出現数を4回以下にする。

## 4. 画像ファイルとアトラス

- 画像生成元のPNGは、差し替え前の版を含めて作業フォルダーに残す。
- アトラスのシンボル順とセル位置を、マニフェスト・合成スクリプト・表示処理で一致させる。
- 公開するアトラスはラスター形式とし、1ファイル25MB未満にする。
- 画像生成後は、対象の種類、全体の収まり、文字の混入、不要な対象、タッチ、非動物の顔なしを目視確認する。

## 5. 変更時の手順

1. 正式名称と画像を決め、画像生成元を保存する。
2. マニフェスト、正式名称一覧、合成スクリプトを同じシンボル順で更新する。
3. 問題生成スクリプトを実行して、4択と正解位置を再生成する。
4. アトラスと人手確認ページを再生成する。
5. 確認ページで全画像と名前を目視し、テストでルールを検証する。

自動検証は `scripts/rebuild-kana-picture-bank.py`、`scripts/generate-atlas-review.py`、Vitestの問題バンクテスト、画像合成テストが担当する。
